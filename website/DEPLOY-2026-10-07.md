## Fixes found during the live check

1. **`/llms.txt` was Yoast's, not the theme's.** Yoast SEO 27.8's llms.txt feature writes a physical file to the web root, which the server returns before WordPress runs, so the theme route never fired. Turned off in Yoast SEO, Settings, Site features, llms.txt. Yoast removed its file and `/llms.txt` now matches `theme/amatec/llms.txt` byte for byte (`text/plain; charset=utf-8`, `X-Robots-Tag: noindex`). Do not turn Yoast's llms.txt back on.
2. **Cache plugin is SpeedyCache, not LiteSpeed Cache.** The brief's "LiteSpeed Cache, Purge All" step is the admin bar's SpeedyCache, Delete all Cache.
